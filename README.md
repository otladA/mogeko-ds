# Mogeko DS

DS homebrew recreation of Mogeko Castle.

Original game by [Deep-Sea Prisoner](https://funamusea.itch.io/).

## Requirements

- [devkitPro](https://devkitpro.org/) with devkitARM
- libnds
- [calico](https://github.com/Gericom/calico)

## Build

```bash
make
```

## Run (melonDS)

```bash
make run
```

Requires [melonDS](https://melonds.kuribo64.net/) installed.
